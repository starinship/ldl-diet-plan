# 降LDL每日飲食

手機優先的單頁靜態網站，提供七日家常餐單，方便想以飲食配合管理低密度脂蛋白（LDL）的人士參考。用字偏向香港、澳門（例如灼、鑊、三文魚、牛油果、番薯）。

用瀏覽器打開 `index.html`，或經 GitHub Pages 由倉庫根目錄提供。頁面會按手機本地星期自動顯示今日餐單，亦可左右滑動切換星期一至星期日。

## 頁面有什麼

- 七日餐單：早餐、午餐、下午小食、晚餐。每款有一人份材料約數和家常煮法。
- 飲食原則：宜多選擇、宜減少的食物。
- 一星期買餸清單。
- 外出用餐和茶餐廳提示。
- 頁尾聲明：這是一般飲食資料，並非醫療建議。

## 檔案

- `index.html`：頁面
- `styles.css`：樣式（含深色模式和安全區域）
- `app.js`：餐單資料和日子切換
- `apple-touch-icon.png`、`favicon.svg`：主畫面和瀏覽器圖示
- `site.webmanifest`：加到主畫面時使用
- `.nojekyll`：讓 GitHub Pages 直接提供檔案

沒有建置步驟，也沒有後端。圖示和樣式都用相對路徑，可在 `https://starinship.github.io/ldl-diet-plan/` 開啟。

本機預覽可在倉庫目錄執行 `python3 -m http.server`，再用瀏覽器打開顯示的網址。
